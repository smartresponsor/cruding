= Canonical Current-Actor Page Migration
:revdate: 2026-08-07

== Status

The former actor-scope URL grammar is removed from Cruding.

Current-user resolution is represented by the terminal `page` operation without an explicit identity token.

[source,text]
----
/vendor/page
/attachment/page
/catalog/page
----

`show` remains an explicit member operation. No legacy prefix compatibility, redirect, collection filter, or API owner-binding behavior is retained.

This historical report file remains only because repository tooling currently prevents physical deletion.
