= Cruding current slice stabilization report
:toc:

== Scope

This report applies only to the current slice derived from `Cruding(17).zip`.

== Applied fixes

=== Canon isolation

* Removed the neighboring `App\Vendoring\` namespace from `CrudEntityClassResolverTest` fixtures.
* Replaced it with local `App\Tests\Fixture\...` metadata names.
* `tools/cruding/interfacing-provider-rendering-guard.php` now passes.

=== Host route safety

The tokenized web and API delivery routes no longer use an unrestricted `.+` requirement.
Both catch-all routes are now bounded by the configured resource-root requirement:

----
%cruding.resource_requirement%(?:/.*)?
----

This preserves PHP-owned token grammar while preventing Cruding from matching roots that are outside its configured resource inventory.

* Removed references to two absent PHPStan stub files.
* Updated Rector PHP set from PHP 8.3 to PHP 8.4.
* Updated PHPUnit schema URL from 10.5 to 12.5.
* Removed a stale `.bak` smoke-test artifact.
